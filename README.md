# UndertaleDialogueMaker

## About

Create your own **Undertale-style dialogue strings** without having to write all the formatting yourself!

UndertaleDialogueMaker features **recurring monsters** and **human(s)** from across the different areas of the game.

**Example:**

`Training Dummy *...`

There's also options for:
- S p a c e d  t e x t
- *WoNkY TeXt*
- **CAPS TEXT**

## Requirements
- Windows 10 or later (64-bit, 32-bit or ARM64)
- [.NET 8 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) (Windows will prompt you to install if missing)

## Disclaimer

The Training Dummy, as stated in the Example, is not present in this software.
